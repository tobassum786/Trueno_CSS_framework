Why Trueno

Everything you need. Nothing you don't.

Built with Sass following best practices — every feature below is a ready-to-use framework class you can drop into your markup today.

🧩

Modular by design

Use only what you need. Every component and utility lives in its own Sass module, so you can tree-shake to a lean build.

📱

Mobile-first

Four breakpoints — sm, md, lg, xl — built mobile-first. Designs reflow gracefully from a phone to a widescreen monitor.

🎨

Theme with ease

Override a handful of Sass variables or switch the built-in dark theme. Try the toggle in the header — this page is themed live.

🗂️

Flexible grid

A 12-column Flexbox grid with auto-layout columns, nesting, and responsive modifiers like col-md-6 and col-lg-4.

⚙️

Essential components

Buttons, cards, and modals — styled with BEM naming and accessible defaults out of the box.

♿

Accessibility first

Semantic HTML, keyboard focus rings, visible states, and WCAG AA contrast built into every component.

Getting Started

Up and running in seconds

Choose npm for modern workflows or a CDN link for quick prototyping.

npm 
npm install trueno-css-framework
// main.js
import 'trueno-css-framework/dist/trueno-css-framework.min.css';
import 'trueno-css-framework/dist/trueno-css-framework.min.js';
CDN 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/trueno-css-framework@1.0.0/dist/trueno-css-framework.min.css">
<script src="https://cdn.jsdelivr.net/npm/trueno-css-framework@1.0.0/dist/trueno-css-framework.min.js"></script>
<!-- Pin the version for production. Start styling -->
index.html — basic usage 
<body>
  <div class="container">
    <h1 class="u-text-center">Hello, Trueno!</h1>
    <div class="row">
      <div class="col-md-6">
        <button class="btn btn--primary btn--lg">Primary</button>
      </div>
      <div class="col-md-6">
        <button class="btn btn--outline-primary btn--lg">Outline</button>
      </div>
    </div>
  </div>
</body>
