# Utilities

Utility classes are single-purpose, composable helpers. They always use `!important` so they win against component styles, and they are prefixed with `u-` so they are easy to spot in markup.

Source: `src/utilities/`

```
utilities/
├── _spacing.scss
└── _helpers.scss
```

---

## 1. Spacing — `_spacing.scss`

A full set of margin and padding utilities generated from a small set of property / side / size combinations.

### Format

```
{property}{side}-{size}
```

| Part | Options |
| --- | --- |
| `property` | `m` (margin), `p` (padding) |
| `side` | `t`, `b`, `l`, `r`, `x`, `y`, or empty (all 4 sides) |
| `size` | `0`, `xxs`, `xs`, `sm`, `md`, `lg`, `xl`, `xxl`, `auto` |

### Generated classes

For each property/side combination, the following sizes are available:

| Class fragment | Value |
| --- | --- |
| `-0` | `0` |
| `-xxs` | `$spacing-xxs` (0.125rem / 2px) |
| `-xs` | `$spacing-xs` (0.25rem / 4px) |
| `-sm` | `$spacing-sm` (0.5rem / 8px) |
| `-md` | `$spacing-md` (1rem / 16px) |
| `-lg` | `$spacing-lg` (1.5rem / 24px) |
| `-xl` | `$spacing-xl` (2rem / 32px) |
| `-xxl` | `$spacing-xxl` (3rem / 48px) |
| `-auto` | `auto` (margin only) |

### Examples

```html
<!-- Margin all sides -->
<div class="m-md">…</div>

<!-- Margin top only -->
<div class="mt-lg">…</div>

<!-- Padding left and right (x axis) -->
<div class="px-xl">…</div>

<!-- Centering a block element -->
<div class="mx-auto">…</div>

<!-- Remove all padding -->
<div class="p-0">…</div>
```

### All available classes

| Property | Side | Example | Result |
| --- | --- | --- | --- |
| Margin | all | `m-md` | `margin: 1rem` |
| Margin | top | `mt-sm` | `margin-top: 0.5rem` |
| Margin | bottom | `mb-lg` | `margin-bottom: 1.5rem` |
| Margin | left | `ml-md` | `margin-left: 1rem` |
| Margin | right | `mr-md` | `margin-right: 1rem` |
| Margin | x (L+R) | `mx-auto` | `margin-left: auto; margin-right: auto` |
| Margin | y (T+B) | `my-md` | `margin-top: 1rem; margin-bottom: 1rem` |
| Padding | all | `p-md` | `padding: 1rem` |
| Padding | top | `pt-sm` | `padding-top: 0.5rem` |
| Padding | bottom | `pb-lg` | `padding-bottom: 1.5rem` |
| Padding | left | `pl-md` | `padding-left: 1rem` |
| Padding | right | `pr-md` | `padding-right: 1rem` |
| Padding | x (L+R) | `px-xl` | `padding-left: 2rem; padding-right: 2rem` |
| Padding | y (T+B) | `py-md` | `padding-top: 1rem; padding-bottom: 1rem` |

> 💡 Replace the `m`/`p` prefix with the desired side letters, and the size token with one of the values in the table above.

### Code reference

The full set is generated by a single `@each` triple-loop in `src/utilities/_spacing.scss`:

```scss
@each $prop, $abbr in (margin, m), (padding, p) {
  @each $dir, $abbr-dir in (top, t), (bottom, b), (left, l), (right, r),
                          (top-bottom, y), (left-right, x), (all, '') {
    @each $size-name, $size-value in (0, 0), (xxs, $spacing-xxs), (xs, $spacing-xs),
                                     (sm, $spacing-sm), (md, $spacing-md), (lg, $spacing-lg),
                                     (xl, $spacing-xl), (xxl, $spacing-xxl), (auto, auto) {
      // emits .#{$abbr}#{$abbr-dir}-#{$size-name}
    }
  }
}
```

### Gap & gutters between layout items

For spacing *between* elements inside a layout — not around a single element — use the gutter system from the [layout layer](./layout.md). It is the same token scale, applied via CSS custom properties:

| Class | Effect |
| --- | --- |
| `g-{size}` | Both axes — sets `--gutter-x` and `--gutter-y` on a `.row` |
| `gx-{size}` | Horizontal only — sets `--gutter-x` |
| `gy-{size}` | Vertical only — sets `--gutter-y` |
| `.grid { --grid-gutter }` | Native `gap` for the CSS Grid system (also `column-gap` / `row-gap`) |

Sizes follow the spacing tokens: `0`, `xs` (4px), `sm` (8px), `md` (16px), `lg` (24px), `xl` (32px).

```html
<!-- Flexbox row: 24px between all columns, vertically and horizontally -->
<div class="row g-lg">
  <div class="col-4">…</div>
  <div class="col-4">…</div>
</div>

<!-- CSS Grid: 16px native gap -->
<div class="grid grid-cols-3" style="--grid-gutter: 1rem;">
  <div>…</div>
</div>
```

> 🎛️ Try the **interactive gap showcase** on the docs site (Utilities page) — a slider drives `--grid-gutter` and `--gutter-x/--gutter-y` live so you can feel each token.

## 2. Helpers — `_helpers.scss`

Single-purpose utility classes for alignment, display, visibility, floating, and clearfix.

### Text alignment

| Class | Effect |
| --- | --- |
| `.u-text-left` | `text-align: left !important` |
| `.u-text-center` | `text-align: center !important` |
| `.u-text-right` | `text-align: right !important` |

```html
<h1 class="u-text-center">Centered title</h1>
```

### Display

| Class | Effect |
| --- | --- |
| `.u-d-block` | `display: block !important` |
| `.u-d-inline-block` | `display: inline-block !important` |
| `.u-d-flex` | `display: flex !important` |
| `.u-d-none` | `display: none !important` |

```html
<div class="u-d-none u-d-md-block">Visible on medium screens and up</div>
```

> ℹ️ The display utilities listed above are the current set. The convention `u-d-{value}` is designed to be extended with `.u-d-inline`, `.u-d-grid`, etc.

### Visibility

| Class | Effect |
| --- | --- |
| `.u-hidden` | `visibility: hidden !important` — element is invisible but still takes space. |
| `.u-invisible` | Extends `%visually-hidden` — element is removed from the visual layout but accessible to screen readers. |
| `.u-sr-only` | Same as `.u-invisible` — for screen-reader-only text. |

```html
<button>
  <span class="u-sr-only">Close</span>
  <span aria-hidden="true">×</span>
</button>
```

### Clearfix

| Class | Effect |
| --- | --- |
| `.u-clearfix` | Extends `%clearfix` — adds a `::after` pseudo-element to clear floats. |

```html
<div class="u-clearfix">
  <img class="u-float-left" src="…" alt="…">
  <p>Text wraps around the floated image.</p>
</div>
```

### Float

| Class | Effect |
| --- | --- |
| `.u-float-left` | `float: left !important` |
| `.u-float-right` | `float: right !important` |
| `.u-float-none` | `float: none !important` |

### Code reference

```scss
.u-text-left   { text-align: left !important; }
.u-text-center { text-align: center !important; }
.u-text-right  { text-align: right !important; }

.u-d-block       { display: block !important; }
.u-d-inline-block{ display: inline-block !important; }
.u-d-flex        { display: flex !important; }
.u-d-none        { display: none !important; }

.u-hidden    { visibility: hidden !important; }
.u-invisible { @extend %visually-hidden; }

.u-clearfix  { @extend %clearfix; }
.u-sr-only   { @extend %visually-hidden; }

.u-float-left  { float: left !important; }
.u-float-right { float: right !important; }
.u-float-none  { float: none !important; }
```

## Utility Best Practices

1. **Use utilities for one-off adjustments.** If you find yourself repeating the same `mb-md` three times in a row, consider promoting it to a component class.
2. **Compose freely.** A single element can have many utilities: `<div class="m-md p-md u-text-center u-d-flex">…</div>`.
3. **Don't override utilities with `!important`.** They are already important by design. If you need to override one, write a more specific selector or use a component.
4. **Use `.u-sr-only` for accessible labels.** It's the right way to provide context to screen readers without affecting the visual design.
