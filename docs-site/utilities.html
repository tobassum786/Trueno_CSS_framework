Utilities

Utility classes are single-purpose, composable helpers. They always use !important so they win against component styles, and they are prefixed with u- so they are easy to spot in markup. Source: src/utilities/

tree
utilities/
├── _spacing.scss
└── _helpers.scss

1. Spacing — _spacing.scss

A full set of margin and padding utilities generated from a small set of property / side / size combinations.

Format

pattern
{property}{side}-{size}
PartOptions
propertym (margin), p (padding)
sidet, b, l, r, x, y, or empty (all 4 sides)
size0, xxs, xs, sm, md, lg, xl, xxl, auto

Generated classes

Class fragmentValue
-00
-xxs$spacing-xxs (0.125rem / 2px)
-xs$spacing-xs (0.25rem / 4px)
-sm$spacing-sm (0.5rem / 8px)
-md$spacing-md (1rem / 16px)
-lg$spacing-lg (1.5rem / 24px)
-xl$spacing-xl (2rem / 32px)
-xxl$spacing-xxl (3rem / 48px)
-autoauto (margin only)

Examples

HTML
<!-- Margin all sides -->
<div class="m-md">…</div>

<!-- Margin top only -->
<div class="mt-lg">…</div>

<!-- Padding left and right (x axis) -->
<div class="px-xl">…</div>

<!-- Centering a block element -->
<div class="mx-auto">…</div>

<!-- Remove all padding -->
<div class="p-0">…</div>

💡

Replace the m/p prefix with the desired side letters, and the size token with one of the values in the table above.

Code reference

The full set is generated by a single @each triple-loop in src/utilities/_spacing.scss:

scss
@each $prop, $abbr in (margin, m), (padding, p) {
  @each $dir, $abbr-dir in (top, t), (bottom, b), (left, l), (right, r),
                          (top-bottom, y), (left-right, x), (all, '') {
    @each $size-name, $size-value in (0, 0), (xxs, $spacing-xxs), (xs, $spacing-xs),
                                     (sm, $spacing-sm), (md, $spacing-md), (lg, $spacing-lg),
                                     (xl, $spacing-xl), (xxl, $spacing-xxl), (auto, auto) {
      // emits .#{$abbr}#{$abbr-dir}-#{$size-name}
    }
  }
}

2. Helpers — _helpers.scss

Single-purpose utility classes for alignment, display, visibility, floating, and clearfix.

Text alignment

ClassEffect
.u-text-lefttext-align: left !important
.u-text-centertext-align: center !important
.u-text-righttext-align: right !important
HTML
<h1 class="u-text-center">Centered title</h1>

Display

ClassEffect
.u-d-blockdisplay: block !important
.u-d-inline-blockdisplay: inline-block !important
.u-d-flexdisplay: flex !important
.u-d-nonedisplay: none !important
HTML
<div class="u-d-none u-d-md-block">Visible on medium screens and up</div>
ℹ️

The display utilities listed above are the current set. The convention u-d-{value} is designed to be extended with .u-d-inline, .u-d-grid, etc.

Visibility

ClassEffect
.u-hiddenvisibility: hidden !important — element is invisible but still takes space.
.u-invisibleExtends %visually-hidden — element is removed from the visual layout but accessible to screen readers.
.u-sr-onlySame as .u-invisible — for screen-reader-only text.
HTML
<button>
  <span class="u-sr-only">Close</span>
  <span aria-hidden="true">×</span>
</button>

Clearfix & Float

ClassEffect
.u-clearfixExtends %clearfix — adds a ::after pseudo-element to clear floats.
.u-float-leftfloat: left !important
.u-float-rightfloat: right !important
.u-float-nonefloat: none !important
HTML
<div class="u-clearfix">
  <img class="u-float-left" src="…" alt="…">
  <p>Text wraps around the floated image.</p>
</div>

Code reference

scss
.u-text-left    { text-align: left !important; }
.u-text-center  { text-align: center !important; }
.u-text-right   { text-align: right !important; }

.u-d-block        { display: block !important; }
.u-d-inline-block { display: inline-block !important; }
.u-d-flex         { display: flex !important; }
.u-d-none         { display: none !important; }

.u-hidden     { visibility: hidden !important; }
.u-invisible { @extend %visually-hidden; }

.u-clearfix  { @extend %clearfix; }
.u-sr-only   { @extend %visually-hidden; }

.u-float-left  { float: left !important; }
.u-float-right { float: right !important; }
.u-float-none  { float: none !important; }

Utility Best Practices

  1. Use utilities for one-off adjustments. If you find yourself repeating the same mb-md three times in a row, consider promoting it to a component class.
  2. Compose freely. A single element can have many utilities: <div class="m-md p-md u-text-center u-d-flex">…</div>.
  3. Don't override utilities with !important. They are already important by design. If you need to override one, write a more specific selector or use a component.
  4. Use .u-sr-only for accessible labels. It's the right way to provide context to screen readers without affecting the visual design.
