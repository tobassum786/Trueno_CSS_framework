Utilities

Utilities are single-purpose, composable helpers for spacing, alignment, display, and visibility. They carry !important so they win against component styles, and they are prefixed with u- (spacing is the exception) so they are easy to spot in markup. Source: src/utilities/

tree
utilities/
├── _spacing.scss   → m-* / p-* spacing scale
└── _helpers.scss   → u-* alignment, display, visibility, float

How utilities work

A utility is a micro-class that does one thing. Stack them on an element to compose layout, and know two rules keep them reliable:

  • They are !important. A utility always beats component styles, so it is impossible for your base CSS to cancel it by accident.
  • They are composable. class="mt-lg u-text-center u-d-flex" is a perfectly valid util-only class list.
⚠️

Because utilities use !important, overriding one requires a more specific selector. If you repeat the same utility three times, promote it to a component class instead.

💡

mx-auto is the idiomatic centerer, but it only centers an element that has a constrained width — pair it with a grid column such as col-6 or an inline width.

Example markup

HTML
<!-- Spacing all sides -->
<div class="m-md">…</div>

<!-- Vertical rhythm: top margin + left/right padding -->
<div class="mt-lg px-xl">…</div>

<!-- Reset padding on a component -->
<div class="card p-0">…</div>

<!-- Center a constrained block -- the col gives it width -->
<div class="col-6 mx-auto">…</div>

Code reference — how it's generated

scss
@each $prop, $abbr in (margin, m), (padding, p) {
  @each $dir, $abbr-dir in (top, t), (bottom, b), (left, l), (right, r),
                          (top-bottom, y), (left-right, x), (all, '') {
    @each $size-name, $size-value in (0, 0), (xxs, $spacing-xxs), (xs, $spacing-xs),
                                     (sm, $spacing-sm), (md, $spacing-md), (lg, $spacing-lg),
                                     (xl, $spacing-xl), (xxl, $spacing-xxl), (auto, auto) {
      // emits .#{$abbr}#{$abbr-dir}-#{$size-name} with !important
    }
  }
}

2. Helpers — u-*

Single-purpose helpers for text alignment, display, accessibility, and layout. All start with u- and are grouped below.

Text alignment

Applied to the same element

.u-text-left — aligned left

.u-text-center — centered

.u-text-right — aligned right

ClassEffect
.u-text-lefttext-align: left !important
.u-text-centertext-align: center !important
.u-text-righttext-align: right !important
HTML
<h1 class="u-text-center">Centered title</h1>

Display

.u-d-inline-block vs .u-d-block — width tells the difference

.u-d-inline-block · 200px
.u-d-block · fills the row

.u-d-flex · centers its child on both axes

item
item

Pair .u-d-flex with framework layout columns for alignment-rich components.

ClassEffect
.u-d-blockdisplay: block !important
.u-d-inline-blockdisplay: inline-block !important

.u-d-nonedisplay: none !important
HTML
<!-- Toggle visibility from JS with a simple class swap -->
<div id="toast" class="u-d-none">…</div>
ℹ️

The current set is block, inline-block, flex, and none. The convention is extensible — add .u-d-inline, .u-d-grid, or responsive variants (u-d-md-none) the same way.

Visibility & accessibility

.u-sr-only attaches a label that screen readers announce but users never see

The trash icon is decorative (aria-hidden); the label is .u-sr-only.
ClassEffect
.u-hiddenvisibility: hidden !important — invisible but still reserves space
.u-invisibleExtends %visually-hidden — removed visually, kept for screen readers
.u-sr-onlyAlias of .u-invisible — the accessibility standard for "screen reader only"
HTML
<button class="btn btn--secondary">
  <span class="u-sr-only">Delete file</span>
  <span aria-hidden="true">🗑</span>
</button>

Float & clearfix

Legacy float with a safe clearfix — prefer the grid for new layouts

.u-float-left
.u-float-right

Text wraps around the floated elements. The parent carries .u-clearfix so its height still contains the floats.

ClassEffect
.u-clearfixExtends %clearfix — a ::after clears floats inside the element
.u-float-leftfloat: left !important
.u-float-rightfloat: right !important
.u-float-nonefloat: none !important
HTML
<div class="u-clearfix">
  <img class="u-float-left" src="…" alt="…">
  <p>…</p>
</div>

Helpers — code reference

scss
// _helpers.scss — the full helper set
.u-text-left    { text-align: left !important; }
.u-text-center  { text-align: center !important; }
.u-text-right   { text-align: right !important; }

.u-d-block        { display: block !important; }
.u-d-inline-block { display: inline-block !important; }
.u-d-flex         { display: flex !important; }
.u-d-none         { display: none !important; }

.u-hidden     { visibility: hidden !important; }
.u-invisible { @extend %visually-hidden; }
.u-sr-only   { @extend %visually-hidden; }

.u-clearfix  { @extend %clearfix; }
.u-float-left  { float: left !important; }
.u-float-right { float: right !important; }
.u-float-none  { float: none !important; }

Utility best practices

  1. Use utilities for one-off adjustments. Repeating mb-md three times? Promote it to a component class.
  2. Compose freely. <div class="m-md p-md u-text-center u-d-flex"> is valid, readable, and the point of the system.
  3. Never strip !important. Override with a more specific selector or a component, never by editing the utility.
  4. Prefer .u-sr-only over hiding tricks. It conveys content to assistive tech without affecting the visual design.
  5. Reach for the grid first. For multi-element layouts, use .row/.col or .grid before compositing floats and margins by hand.
