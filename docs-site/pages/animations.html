Animations & Transitions

Trueno CSS ships a complete motion system — design tokens, a keyframe library, and utility classes — so animations stay fast, accessible, and on-brand. Everything below runs the live framework build: what you see is what you ship.

♿

Motion respects prefers-reduced-motion. Users who request reduced motion get near-instant transitions automatically — no extra work on your side.

4. Scroll reveal

The .reveal helper hides an element and slides it in when .is-visible is added. Scroll down — the rows below reveal as they enter the viewport.

Reveal 1 · .reveal.is-visible
Reveal 2 · stagger with --tr-delay
Reveal 3 · observe + unobserve
js
const observer = new IntersectionObserver((entries) => {
  entries.forEach((entry) => {
    if (entry.isIntersecting) {
      entry.target.classList.add('is-visible');
      observer.unobserve(entry.target);
    }
  });
}, { threshold: 0.15 });

document.querySelectorAll('.reveal').forEach((el) => observer.observe(el));
